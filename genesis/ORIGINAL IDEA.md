# Original Idea — Tosh Company Ecosystem

Tosh Company is the ecosystem around a set of focused macOS applications. The apps should feel like members of one family rather than unrelated tools. When a new Tosh app is created, its agents and developers must understand the shared identity, design language, technical boundaries, and marketplace before building inside the app.

NotchinTosh, LaunchinTosh, LockinTosh, SwitchinTosh, and CleaninTosh are separate products in that ecosystem. A shared Tosh Marketplace will later let people discover and install compatible widgets, extensions, and other app components. The marketplace belongs to the ecosystem; individual apps consume it through host-specific contracts.

This root project is the ecosystem documentation and coordination layer. It should define the shared rules without absorbing each app's implementation code.
